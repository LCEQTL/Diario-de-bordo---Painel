# Diário de Bordo · painel do gestor e do admin

Site estático (GitHub Pages) que conversa direto com o Supabase.

- **Dashboard:** produtividade com filtros por período, setor, cargo, tarefa e colaborador, e tamanho do armazenamento (só admin).
- **Registros e evidências:** todos os lançamentos, visualização das fotos, exportação para Excel e limpeza de fotos antigas (só admin).
- **Pessoas:** cadastro individual ou por planilha, senha temporária e gestores de teste.
- **Setores, cargos e tarefas:** a estrutura de cada setor, com importação por planilha.

Edite só o `config.js`. Como publicar: veja o `TUTORIAL.md` que veio no pacote.
